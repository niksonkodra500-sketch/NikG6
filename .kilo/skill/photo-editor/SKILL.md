# NikG6 Photo Editor - Project Skills

This skill provides context for working with the photo editor codebase.

## Architecture

- **Frontend**: React + TypeScript + Vite
- **Canvas**: Fabric.js for image editing
- **AI Assistant**: OpenRouter integration with tool calling
- **Mobile**: Capacitor for Android
- **Testing**: Vitest (unit) + Playwright (e2e)
- **Build**: GitHub Actions CI/CD

## Key Files

- `src/editor/` - Core editor logic (adjustments, history, commands, filters)
- `src/ai/` - AI assistant (tools, OpenRouter client, assistant loop)
- `src/components/` - React UI components
- `src/storage/` - Persistence layer (Capacitor Preferences/SecureStorage)
- `src/App.tsx` - Main app component
- `src/main.tsx` - Entry point

## Common Tasks

- Add new filter: Edit `src/editor/fabricFilters.ts` and `src/editor/types.ts`
- Add new adjustment: Edit `src/editor/adjustments.ts` and `src/editor/types.ts`
- Add new AI tool: Edit `src/ai/tools.ts`
- Modify AI behavior: Edit `src/ai/assistant.ts` and `src/ai/presets.ts`
- Run tests: `npm test` (unit), `npm run e2e` (e2e)
- Build Android: `npx cap sync android && cd android && ./gradlew assembleDebug`

## Testing

- Unit tests in `*.test.ts` files alongside source
- E2E tests in `e2e/*.spec.ts`
- Sample image: `public/sample.png` (generated by `node scripts/generate-sample.mjs`)
